Install and activate

Three steps to get started.

The APK can be downloaded before or after purchase. A valid Praecheck licence file is still required for licensed use.

1

Download & install

Download the APK and open it on your Android device. Android may ask you to allow installation from your browser or file manager.

2

Buy a licence

Optional file verification

Want to verify the download?

Most people can simply use the official Download APK button above. For an extra integrity check, the SHA-256 checksum lets you confirm that the file you received matches the published Praecheck release.

1

Windows

Open PowerShell in the folder containing the APK and run Get-FileHash .\Praecheck-v0.9.3.apk -Algorithm SHA256. Compare the result with the downloaded checksum file.

2

Android / Linux

If you use Termux or Linux, keep the APK and checksum file in the same folder and run sha256sum -c Praecheck-v0.9.3.sha256. A matching file reports OK.

3

No command line?

That is fine. Download Praecheck only from this official page. The checksum is an optional extra check for people who want to verify the downloaded file themselves.
