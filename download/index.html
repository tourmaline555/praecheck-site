Installation and activation

Install, license and activate.

The signed APK may be downloaded before or after purchase. Licensed operation requires a valid signed Praecheck .pcl licence file.

1

Install the signed APK

Download the current production APK and install it on the Android device. Android may require installation permission for the browser or file manager used.

2

Purchase a licence

Personal supports up to 2 personal devices; Power supports up to 10. Payment processing is provided by Paddle.

3

Issue the offline licence

Copy the Installation ID from Praecheck and submit it with the Paddle purchase reference on the activation page to obtain the signed offline .pcl licence.

Release integrity

Verify the published SHA-256 digest.

The checksum provides an independent integrity check that the downloaded APK matches the published Praecheck release.

1

Windows

Open PowerShell in the folder containing the APK and run Get-FileHash .\Praecheck-v0.9.3.apk -Algorithm SHA256. Compare the result with the downloaded checksum file.

2

Android / Linux

If you use Termux or Linux, keep the APK and checksum file in the same folder and run sha256sum -c Praecheck-v0.9.3.sha256. A matching file reports OK.

3

Official distribution path

Use the Praecheck download page and the downloads.praescius.org.uk release host. Checksum verification is available when independent file-integrity validation is required.

v0.9.3 release scope

Longitudinal assessment and device context.

Bounded assessment history

Retain a local timeline of up to 50 assessments with version and role context.

Change and regression state

Identify new, resolved, unchanged and returned findings between compatible assessments.

Reassessment planning

Record a local 30, 60 or 90-day recheck interval and reassess after material device changes.

Device-role context

Associate Everyday, Banking, Work, Travel, Privacy-focused or Custom context without altering Core scoring.

Version-aware comparison

A changed assessment model starts a new comparison baseline rather than creating false device regressions.

Personal-use licensing

The same assessment capabilities are available with 2-device Personal and 10-device Power licences.
