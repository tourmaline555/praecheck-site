Activate Praecheck

Create the offline licence file for your Praecheck Personal purchase. You will need the email address used at checkout and the installation code shown by Praecheck on the device you want to activate.

Payment reference received. Enter your purchase email and this device's Praecheck installation code to create the licence file.
Use the same email address used for the Praecheck purchase.
This is filled automatically after checkout. If you opened this page separately, enter the Stripe Checkout Session ID beginning with cs_live_.
In Praecheck, copy the installation code from the licence/activation screen on this device.
After the .pcl file downloads, open Praecheck on the same device and import the licence file. A Personal licence supports up to two personal devices.
Activation sends your purchase email, Stripe purchase reference and Praecheck installation code to the Praecheck licensing service. Praecheck assessment results are not uploaded.
