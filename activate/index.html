Licence activation

Activate Praecheck

Praecheck Personal covers up to 2 devices.
Each device needs its own signed .pcl licence file. If you already activated your first phone, use the same purchase email and purchase reference here with the installation code shown on your second phone. Do not copy the first phone's .pcl file to the second phone.

Create the offline licence file for your Praecheck Personal purchase. You will need the email address used at checkout and the installation code shown by Praecheck on the device you want to activate.

Payment reference received. Enter your purchase email and this device's Praecheck installation code to create the licence file.

Activate this device

  1. Open Praecheck on the device you want to activate and copy its installation code.
  2. Enter the same purchase email and purchase reference from your original Personal purchase.
  3. Create and download the new .pcl file, then import that file on this device.
Activating device 2 does not replace device 1. It uses the second seat included with Praecheck Personal.
Use the same email address used for the Praecheck purchase.
Second device? On device 1 open Licence & privacy → View licence details and enter its Licence ID (starts PC-). Use the same purchase email. Immediately after checkout, a purchase reference may be filled automatically.
Use the installation code shown by Praecheck on the device you are activating. Each device has a different installation code.
After the .pcl file downloads, open Praecheck on the same device and import the licence file. A Personal licence supports up to two personal devices.
Activation sends your purchase email, Stripe purchase reference and Praecheck installation code to the Praecheck licensing service. Praecheck assessment results are not uploaded.
